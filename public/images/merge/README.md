# Margin Merge artwork

32 original item renders generated with the built-in image_gen tool for this
project. No stock imagery or emoji artwork is embedded. Each chain has eight
tiers; item identities match the existing game saves.

Files: `{heroes,paper,tools,creatures}-{1..8}.webp`.
192 × 192 pixels, transparent alpha, locally served. Original PNG renders were
resized and encoded with ImageMagick at quality 88. The complete production
prompt set is preserved in `prompts.json`.

The CC0 audio dedication applies to audio and its generator only; it does not
make a claim about copyright ownership or licensing of generated artwork.
